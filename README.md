# MERN-Notes-App

This project has empowered me in multiple skills:

## Core Skills Covered
- Full-stack web development with MERN
- Building a REST API with Express
- Creating and managing a MongoDB database with Mongoose
- Creating React pages and reusable UI components
- Using Axios to connect frontend and backend
- Working with routes, forms, and navigation
- Implementing loading and error states
- Applying styling with Tailwind CSS and DaisyUI
- Adding simple API protection with rate limiting

## Learning Focus
- Frontend development
- Backend development
- Database integration
- API design
- Project organization
- UI/UX basics

## Good Practice Areas Demonstrated
- Clean folder structure
- Separation of concerns between routes, controllers, and models
- Environment-based configuration
- User-friendly feedback through notifications

## Outcome
By completing this project, I've strengthened my understanding of how modern web applications specifically MERN apps  are built and connected end to end.

## 🧪 .env Setup

### Backend (`/backend`)

```
MONGO_URI=<your_mongo_uri>

UPSTASH_REDIS_REST_URL=<your_redis_rest_url>
UPSTASH_REDIS_REST_TOKEN=<your_redis_rest_token>

NODE_ENV=development
```

## 🔧 Run the Backend

```
cd backend
npm install
npm run dev
```

## 💻 Run the Frontend

```
cd frontend
npm install
npm run dev
```
